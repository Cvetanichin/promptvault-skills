Review the following prompt: [PASTE PROMPT]. Version: [vXX]. Identify: (1) What this version does well, (2) What fails or underperforms, (3) Proposed improvements with rationale. Produce version [vXX+1] with changes tracked in a changelog block.
Changelog format: Change | Reason | Expected impact

When invoked, ask the user to specify: [PASTE PROMPT] before proceeding. If the user already supplied this information in their request, use it directly instead of asking.
