Rewrite the following feature-focused text as compelling, benefit-led copy:

[PASTE FEATURE DESCRIPTION / ACTIVITY TEXT]

Audience: [DONOR / BOARD / COMMUNITY / PUBLIC / JOURNALIST]
Context: [GRANT APPLICATION / ANNUAL REPORT / WEBSITE / SOCIAL MEDIA]
Tone: [FORMAL / CONVERSATIONAL / INSPIRATIONAL / EVIDENCE-BASED]

Rules:
1. Lead with the human outcome, not the activity
2. Use specific numbers (people, %, €, days) wherever possible
3. Replace ‘we deliver’ with ‘X people now…’ or ‘Y% improvement…’
4. One sentence per idea. Max 25 words per sentence.
5. End with a forward-looking statement

Output:
1. Rewritten version (max [WORD COUNT] words)
2. Original → rewritten comparison for 3 key phrases
3. One pull-quote for social media (max 140 characters)

When invoked, ask the user to specify: [DONOR / BOARD / COMMUNITY / PUBLIC / JOURNALIST], [FORMAL / CONVERSATIONAL / INSPIRATIONAL / EVIDENCE-BASED], [GRANT APPLICATION / ANNUAL REPORT / WEBSITE / SOCIAL MEDIA], [PASTE FEATURE DESCRIPTION / ACTIVITY TEXT], [WORD COUNT] before proceeding. If the user already supplied this information in their request, use it directly instead of asking.
