---
name: iterative-refinement-protocol
description: "Refined, polished output through 3 iterations."
---

Improve [OUTPUT TYPE] through 3 rounds:
Round 1: Produce a first draft of [TASK].
Round 2: Critique the draft against [CRITERIA]. Identify top 3 weaknesses.
Round 3: Revise to address all 3 weaknesses.
Present only Round 3 output and a brief improvement note (max 50 words).

When invoked, ask the user to specify: [CRITERIA], [OUTPUT TYPE], [TASK] before proceeding. If the user already supplied this information in their request, use it directly instead of asking.
